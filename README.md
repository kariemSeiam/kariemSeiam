**Work**

- **[HVAR](https://me.kariem.dev/work/hvar/)**: one order, four systems, and the work of keeping their truths from contradicting each other.
- **[Geolink](https://me.kariem.dev/work/geolink/)**, founded by me: Egypt's own maps API for search, directions and geocoding. Four rewrites deep, still live.
- **[Taxiarab](https://me.kariem.dev/work/taxiarab/)**: ride-hailing, live in Jordan. I own where it fails silently: services, sockets, invites.
- **[Ataya](https://me.kariem.dev/work/ataya/)**: a shop's counter, web store and in-store kiosk, on one ledger that only records what happened.
- **[Dinamo](https://me.kariem.dev/work/dinamo/)**: Egyptian ride-hailing. I owned how the driver app hears about a trip.

**Open here**

- **[plumb](https://github.com/kariemSeiam/plumb)**: quiet pipes for noisy agents. Wraps any CLI coding agent as an A2A server. On npm as `plumb-bridge`.
- **[geolink-mcp](https://github.com/kariemSeiam/geolink-mcp)**: Geolink for AI agents over MCP: geocoding, place search, routing, area sweeps. Remote server at `geolink.kariem.dev/mcp`.
- **[pixy-open](https://github.com/kariemSeiam/pixy-open)**: a root-shell model of a live Android phone that knows *why* it believes what it reports.

**How I work**

Every date and count on my site is computed from its source at build time, and a script fails the build when one of the site's standards breaks. When part of a system I built didn't work, its case study says so.
